# Store assets

The App Store screenshots and preview are generated, not drawn. Start `node tools/store/worker.mjs`, which answers the demo with one fixed question and the seeded history's notes, and run the store suite on an iPhone 17 Pro Max simulator with the Demo row hidden: `TEST_RUNNER_OOOOH_WORKER_URL=http://127.0.0.1:8790 xcodebuild ... -only-testing:oooohUITests/StoreCaptureTests -resultBundlePath store.xcresult test`. `export-captures.sh store.xcresult <captures>` copies the screenshots out by name, and `render.sh <captures> <out>` serves `shots/*.html` over the site's CSS and the orb canvas and screenshots each one with headless Chrome at 1320 by 2868, 1284 by 2778, and 1206 by 2622, the three iPhone sizes App Store Connect asks for. Each template is one caption of at most seven words over a phone frame drawn in CSS with the real capture inside. For the preview, run each test method on its own with `xcrun simctl io <device> recordVideo <name>.mov` running alongside, write `shots.tsv` beside the clips (clip, start second, duration, caption, tab separated, one row per shot in `storyboard.md`), and `preview.sh <clips> <out.mp4>` cuts them into the 886 by 1920, 30 fps, silent stereo file App Store Connect accepts. Rendered files stay out of the repo.
